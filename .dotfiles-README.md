# Dotfiles Setup

This repository contains my personal dotfiles configuration.

## Initial Setup on a New Machine

1. Clone the dotfiles repository:
   ```bash
   git clone --bare <your-dotfiles-repo-url> $HOME/.dotfiles
   alias dotfiles='/usr/local/bin/git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME'
   dotfiles checkout
   ```

2. Set up environment variables:
   ```bash
   cp ~/.env.template ~/.env
   ```

3. Edit `~/.env` with your actual API keys and tokens:
   ```bash
   vim ~/.env  # or your preferred editor
   ```
   
   Fill in the values for:
   - GEMINI_API_KEY
   - NOTION_TOKEN
   - ONFIDO_API_KEY
   - HONEYBADGER_API_KEY & PROJECT_ID
   - JIRA_URL, USERNAME, API_TOKEN
   - CONFLUENCE_URL, USERNAME, API_TOKEN

4. Reload your shell configuration:
   ```bash
   source ~/.zshrc
   ```

## Transferring to Another Machine

When moving to a new machine, you only need to:

1. Follow the "Initial Setup" steps above
2. Copy your `.env` file from your old machine to the new one:
   ```bash
   # On old machine
   cat ~/.env  # Copy the contents
   
   # On new machine
   vim ~/.env  # Paste the contents
   ```

## Security Notes

- **NEVER** commit the `~/.env` file - it contains your sensitive credentials
- The `.env` file is already git-ignored
- Use `.env.template` as a reference for what variables need to be set
- Google Cloud credentials are managed separately via `gcloud` CLI

## Files Excluded from Git

The following sensitive files/directories are excluded via `.gitignore`:
- `~/.env` - Your actual API keys and tokens
- `~/.config/gcloud/` - Google Cloud credentials
- `~/.config/configstore/` - Various tool configurations with tokens
- `~/.config/opencode/opencode.json` - OpenCode configuration (may contain keys)
- `~/.config/github-copilot/hosts.json` - GitHub OAuth tokens

## Adding New Credentials

When you need to add a new API key or token:

1. Add it to `~/.env`:
   ```bash
   echo 'export NEW_API_KEY=your_key_here' >> ~/.env
   ```

2. Update `.env.template` with a placeholder:
   ```bash
   echo 'export NEW_API_KEY=your_new_api_key_here' >> ~/.env.template
   ```

3. Commit the `.env.template` update:
   ```bash
   dotfiles add ~/.env.template
   dotfiles commit -m "Add NEW_API_KEY to env template"
   ```
